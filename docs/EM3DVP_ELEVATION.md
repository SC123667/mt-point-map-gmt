# 自动获取地形并导出 EM3DVP 高程

入口：**输出与软件 → EM3DVP 高程导出**。可以使用当前图幅和地形设置，也可以单独填写西、东、南、北边界和分辨率。无需选择 GRD 文件，不改变当前地图范围。

点击“一键获取地形并导出 EM3DVP 高程”后：

1. 优先检查当前已导入且覆盖范围的本地地形。
2. 匹配地形底图同一缓存中的当前范围，或覆盖它的同分辨率区域缓存。不把阴影、预览及处理中网格当成原始高程。
3. 缓存不足时复用地形底图的 GMT/SRTM 准备流程、下载源及“允许下载”设置；禁止联网时仍只使用可用的本地数据。没有可用数据则报告错误。
4. 后台提取范围内原始高程格点，生成无表头三列文件 `elevation_lonlat.xyz`：经度（度）、纬度（度）、高程（米）。无需转换为 UTM、旋转坐标或模型深度；海拔和海底负值保留。

文件保存到：**全局目录 / 导出高程 / EM3DVP / 地名 + 经纬度范围 + 时间与唯一编号**。每次导出保留独立结果，并附来源、原始和实际范围、分辨率、抽样步长、点数、缺测统计和导入说明。名称中的城镇只供检索，不代表行政或地质边界。未挂载外置盘时明确提示，不创建伪挂载目录，也不偷偷切换到其他缓存。

“抽样步长”同时作用于经纬两个方向：1 保留全部原始格点，2 每隔一个格点抽取；不会插值或增加源数据精度。范围边界未落在原始节点上时，实际格点范围会略小，详见 JSON。最多读取 2500 万个原始格点、输出 500 万点；过大时缩小范围或调整分辨率/抽样。

默认遇到 NaN/无效高程即停止；可明确选择跳过，不用零补齐。至少需三个不共线点。GRD 必须为经纬度网格；未声明坐标类型的文件需要明确确认，投影坐标需要先重投影。高程单位可选择米、千米、英尺，已声明的单位冲突会报错；高程基准沿用源数据，不进行椭球高与正高转换。跨日期变更线需分区导出。

## EM3DVP 格式依据

本地 EM3DVP 的 `src/add_topobathy.m` 通过 `readmatrix(...,'FileType','text')` 读取 XYZ，再调用 `src/interpolate_topography_grid.m`。后者规定前三列为经度、纬度、高程，要求有限值，并自行投影和插值到模型网格。在 EM3DVP 加载 EDI、生成模型后，通过“添加地形/水深”选择 `.xyz`，也可用于其精细地形设置。

建议高程覆盖核心模型范围；EM3DVP 自己会对缺测/外延执行相应插值，导出器不把这种填补伪装成实测高程。未改动 EM3DVP 源码。
