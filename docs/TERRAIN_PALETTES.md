# B / C / F 地形配色（v1.32.1）

新工作台默认使用 F（每 500 m 分级），打开已有工程则恢复该工程保存的配色。

进入“地形底图 → 色带”选择：

- **B · 增强绿褐**：连续绿褐渐变，增强高低层次。
- **C · 经典分层地形**：连续绿—黄—褐—灰白；明度并非全程单调，应结合高程颜色含义阅读。
- **F · 分级设色（默认 500 m）**：每个高度区间使用同一填色；分级宽度跟随“高程色标 → 刻度间隔 / m”，默认 500 m。边界是人为设色分级，不代表地质界线。

方案只改变地形颜色，不套用其他样式或修改原始高程、测点、MT 数值。原有配色仍可选择，打开旧工程不会自动改成 B / C / F。选择随工程保存并支持撤销。普通地图沿用自动预览；相位张量 / 感应矢量修改后点击“更新预览”。

上下限由“高程色标”的高程范围控制，默认 0–3500 m，此时三套 CPT 与 2026-11-03 的 B / C / F 预览逐字一致。B / C 的颜色节点随范围线性缩放；F 从下限开始按刻度间隔分级，最后一段截到上限，颜色均匀分配至全部级别。为避免误设大量分级，超过 1000 级时提示增大刻度间隔。m / km 显示单位不改变输入的米制范围。

在“地形底图 → 高程色标”分别设置区域底图和点位图的色标。区域底图默认开启，点位图默认关闭。各格式导出使用同一 CPT。仅更换配色无需重新下载地形。

实现：electron/terrain-palettes.js 维护三个配色和离散分级；gmt.js 在普通地图与 MTpy 背景统一生成 CPT，沿用预览中的中性照明设置。验证：tests/terrain_palettes.test.js 与 tests/terrain_palettes_integration.cjs，另以真实 MTpy 相位张量 / 感应矢量验证色带传递与 AI 图层。记录在全局目录/验证/v1.32.0。
