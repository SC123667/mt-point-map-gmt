# 高程色标（v1.33.1）

打开“地形底图 → 高程色标”。“区域底图显示高程色标”默认开启，“点位图显示高程色标”默认关闭。勾选所需图件的开关，启用地形并更新预览，色标默认在图框下方居中。旧工程沿用原区域底图设置，首次打开时点位图开关关闭。

参数随工程保存并支持撤销。高程范围仍控制各类图件的地形配色，切换图件不会重置范围。

默认勾选“按 EDI 测区自动设置上限与间隔”。读取当前图幅内有效测点高程（单位米），再用已准备的地形峰值校核；取二者较大值，上限向上取整，间隔从 1、2、2.5、5 × 10ⁿ 中选择整数，优先约 6–8 个色阶。零高程有效，空值、非数值和 -9999 缺失标记跳过，不修改原 EDI。

例如测点最高 2454 m，尚无地形时先估算上限 2500 m、间隔 500 m；当前测区地形峰值约 3060 m，校核后使用 3500 m / 500 m。最高 7800 m 时取 8000 m / 1000 m。未得到有效高程时保留已有数值；新工程回退为 3500 m / 500 m。状态文字区分测点估算与地形校核。地形准备后，点击更新预览即可更新数值；自动范围自身不触发下载。

手动修改上限或间隔会取消自动，重新勾选即可恢复。自动开关随工程保存并支持撤销；未保存该开关的旧工程首次打开默认启用，原文件不会被自动改写。下限仍手动设置（默认 0 m），不随上限自动改变；海域或负高程区域可自行调低下限。高程字段同时适用于已导入的点位表。

预览、导出、GMT 脚本和 MTpy 地形背景在出图前使用同一计算。已有正式分辨率地形缓存时，快速预览也优先用它校核；仅有低分辨率地形时先采用该网格，后续高分辨率地形可能使上限调整。局部图幅只读取该范围，结果按网格文件与范围缓存，不轮询。

长度 45 mm、厚度 2.5 mm、字号 7 pt、间距 8 mm。显示单位可切换 m / km；范围与间隔输入始终为米。水平对齐、偏移和图下间距可直接调整。

底图与色标共用同一 CPT，修改范围会同步改变底图配色，但不修改高程网格和 MT 数据。两端三角说明范围外使用端点颜色；地形阴影的明暗不代表另一种高程。隐藏色标保留当前配色范围；关闭地形时不输出高程色标。连续色带在 PDF 中可能是小型栅格条，刻度与说明文字保留矢量；MTpy AI 不输出高程色标图层。

旧工程缺少其他参数时使用上述默认值，不修改原工程文件。

验证：tests/terrain_colorbar.test.js、tests/terrain_colorbar_integration.cjs 覆盖区域底图显示、m/km、隐藏、无地形和点位图的独立开关；tests/phase_coloring_integration.cjs 检查真实 MTpy 相位张量 / 感应矢量 PDF 与 AI 图层均无高程色标，保留相位色标。记录位于全局目录/验证/v1.31.1。

应用只保留“实用app”内的最新版本，替换前的 App 移入废纸篓；源码通过本地 Git 提交与标签回滚，不上传 GitHub。不改写用户工程、EDI 或地形网格。

自动范围验证：tests/terrain_autoscale.test.js 检查整数间隔、向上覆盖、无效高程、手动覆盖、图幅裁切和长路径；tests/terrain_autoscale_integration.cjs 使用实际 81 测点工程验证后台出图、界面回填、保存和撤销。
