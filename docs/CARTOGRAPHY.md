# 地点、构造与等高线

本地 v1.7.0。无需导入 MT 点位，选择区域底图、设置经纬度，然后使用左侧“图层”中的三个入口。

## 编辑对象

“地点与构造”支持点、线、面。点填一行经纬度，线填多行，区域自动闭合；经度在前、纬度在后，单位为十进制度。Excel 批量地点采用“名称、经度、纬度、类别”四列，最后一列可省略。SHP 读取同名 PRJ 自动转到 WGS84；缺少 PRJ 的米制数据会被拒绝，请补充坐标定义。GeoJSON 要求 WGS84 经纬度，支持多点、多段线、多面和带孔多边形。复杂几何可直接编辑 GeoJSON 坐标。

每项可以独立设置名称、简称、自定义换行文字、字体、字号、白色描边、标注位置、偏移和旋转，或将当前样式应用到同类别所有对象。线有颜色、粗细和实线/虚线/点线，点有符号和大小，区域有填色和不透明度。修改对象后点击“保存对象”，也可以直接确认面板保存当前草稿。已保存的对象修改实时进入工程状态；“取消”关闭面板，不撤销已保存对象。

默认标注锚点在可见线顶点或区域中心，可在精细设置中指定另一个经纬度。文字偏移单位为图上毫米，不改变原始构造坐标。可通过选择对象和上一个/下一个逐项编辑、隐藏或移除；移除工程对象不会删除下载的数据文件。

查询支持关键词和当前地图范围。来源缺少构造名称时保留“未命名”及原始属性，软件不推测地质名称。雅鲁藏布、班公、怒江等常用中文关键词支持匹配对应英文名称。公共数据查询一次最多显示 1000 项，超过时明确提示缩小范围；服务/文件导入上限 20000 项，超出会提示。重复添加相同来源要素会去重。

WFS 支持 2.0/1.1 能力查询与 GeoJSON 输出，请求 CRS84 经度在前的坐标，并保留来源实际返回的坐标定义检查。未支持 GeoJSON 输出的 GML 专用服务需先从提供方下载 SHP/GeoJSON。WMS 只有图片，不能作为可编辑构造矢量导入。网络、权限和服务覆盖范围由数据提供方决定，软件会显示实际错误。

数据下载、SHP 解码与重投影、筛选在独立后台进程中执行。首次下载后缓存完整公开数据；WFS 缓存每次服务、图层与范围的结果。缓存与来源 JSON 位于全局目录 `构造数据/来源名称`，保留 URL、许可、文献、SHA-256、下载时间。相同查询优先离线读取；“更新本地数据”重新获取公开数据库或当前 WFS/GeoJSON 服务结果；原工程仍保留已有坐标。

数据编译精度、原始比例尺和年代并不一致。构造区域填色表示来源的地质几何，不能自动生成某篇论文特定解释的构造边界。论文出图应引用所使用数据及原始文献，导出目录内的 `图层来源.json` 保留这些信息。

## 等高线

从“地形底图”设置来源、分辨率或本地 GRD/NC。等高线开关独立于晕渲，可生成纯矢量等高线图。设置普通和主等高距、线宽、颜色、高程字号、数字最小间距及短线过滤（图上厘米）。图幅较大时建议适当加大等高距和数字间隔。

预览采用适合画布的较轻网格，导出按用户选择的分辨率计算。预览与高分辨率导出的细小等高线可能不同；加密显示不能提升原始 DEM 的真实精度。同样式构造合并为批量 GMT 绘图，避免上千次单独调用。

## 工程、输出与 Illustrator

所有坐标、样式、显隐和等高线配置保存到 `.mtgmt` 的 `config.cartography`。旧工程缺少此字段时使用空图层与关闭的等高线。

PDF 中地图线条、符号、中文名称、等高线是矢量内容，中文文字保留为可提取的文本；白色描边会带来文本描边与填充两次绘制。字体在 Illustrator 上继续修改时仍需本机安装相应字体。地形晕渲为影像。EPS 经矢量 PDF 转换包含中文，优先用 PDF 编辑。软件还导出 `自定义标注.svg`、`地图图层.geojson`、`图层来源.json` 和 GMT 输入文件，均放在全局目录的地名/范围分类下。必要的辅助 PDF/EPS 可在原生标注处理时一并生成。

GMT 脚本复现地图和构造几何；中文原生标注由桌面渲染步骤生成，纯 GMT 单独运行不会生成这一原生文字层。需要完整复现时保存并重新打开 `.mtgmt`，或在相同画幅上使用随图导出的 SVG 标注。手动添加对象也可单独导出 GeoJSON 与样式 JSON。

## 本轮验证边界

实际下载核对：HimaTibetMap 940 条构造要素、18 条缝合带要素、90 个火山岩要素；GEM 16195 条断层；PB2002 241 条边界、54 个板块。数量对应本轮获取的文件，后续上游更新可能改变。真实 SARIG WFS 查询返回 128 条南澳断层（138–139°E、33–32°S）。

GMT 6.5.0 实际验证：青藏 86–96°E、28–32°N，真实 30 秒高程、城市、雅鲁藏布缝合带、区域面和等高线；PNG/PDF/EPS、地形开/关、交换坐标轴、中文文本与工程恢复。Windows 仅验证界面布局和保留 ASCII 工作区逻辑，未进行 Windows 实机运行。

## v1.7.0 地图节点与双语名称

先生成预览，然后在“地点与构造”选择画线/画区域。依次点击地图形成节点；“完成绘制”保存几何并返回对象面板，设置名称、线宽、线型和颜色后确认更新。选中现有对象后可拖动节点，在线段附近（24 屏幕像素内）插入节点，选中节点后删除；撤销仅影响本次编辑，取消放弃本次未完成的几何修改。带孔区域与多段线保留各组成部分。编辑期间暂停自动出图，完成或取消后再导出。

绘图语言与名称形式是工程级设置，统一覆盖图层的单项名称形式；原始名称模式继续兼容旧工程的自定义文字。双语名称均可换行。内置词表覆盖常用地名、类别及部分构造名称，不是任意地名的自动翻译服务；外部 name:zh/name:en 字段直接使用。无译名的对象仍绘制几何，文字暂不显示，并提示补全；类别译名可独立填写以生成统一语言的自动图例。用户自定义标题与 MT 测点编号不当作外部地名自动翻译。

“记住名称修订”把该来源对象的双语名称和简称存入 `名称词典/用户中英文名称.json`。重新导入同一对象时优先使用该修订，不覆盖坐标和原始名称，也不直接改写历史工程。工程自身保存完整名称信息，迁移到其他电脑也可保持图件语言。

联合查询覆盖六组已接入公开矢量，按当前范围、名称/简称和几何形状筛选，已有缓存可离线查询。SNM、某篇论文的 Jurassic Arc 等未必在这些库中具备对应几何；应从原文数据或其他可靠来源取得线/区域，或明确标记为手工描绘。名称词表不会生成构造边界。


## 论文构造地形图（v1.9.0）

在绘图预设或“本地构造库”面板选择“论文构造地形图”。它应用低饱和度地形色带、0.25 阴影强度、较细图框、较短比例尺与 7–7.5 pt 构造字体；“论文浅灰底图”使用中性灰色。已选地形分辨率、构造类别、来源和坐标保持。预览仍使用已有的预览网格策略，导出遵循所选分辨率。

缝合带使用暗红虚线，断层使用蓝灰/炭灰细线，次要边界用浅灰。编号或缺少真实名称的线条弱化显示，不删几何、不推断名称。不同来源的近似线仍可能重复，需在本地库取消不需要的来源。配色是本软件提供的展示预设，不代表期刊统一规定。

名称优先使用可靠的统一语言字段。开启“自动排布”后，按实际 GMT 投影位置和图框尺寸寻找沿线候选位置，限制密度、去重、旋转并避让其他文字和比例尺/图例预留区域。字宽采用保守估计；复杂曲线和密集交叉仍需人工审阅，必要时编辑标注锚点和字体。手动锚点优先，两个相互冲突的手动锚点不会强制移动。开启“隐藏未命名/文件编号”后，文件名加线段号不会印在地图上；可关闭该选项用于数据核对。

输出目录 `标注排布报告.json` 记录本次显示数量及隐藏对象、原因：generic（编号/未命名）、duplicate（重复）、density（密度限制）、collision-or-edge（遮挡或边缘）。关闭自动排布恢复原有锚点排布。地形栅格与构造矢量分别保持；PDF 和配套 SVG 保留可编辑文字，EPS 由含文字的矢量 PDF 转换。独立 GMT 脚本不能自行执行 Electron 的原生文字叠加，完整标注以软件导出的 PDF/SVG 为准。
