# 相位张量着色（v1.31.0）

“相位张量 → MTpy 参数 → 椭圆着色量”提供 β、最小相位 φmin、最大相位 φmax 和 **Φ₂ 等效相位（°）**。修改后点击“更新预览”；参数随工程保存并支持撤销。默认仍为 β，旧工程保存的选择不变。

最大相位使用 MTpy-v2 2.1.4 的 `PhaseTensor.phimax`。最小相位、最大相位和 Φ₂ 等效相位统一使用 `mt_bl2gr2rd` 色带与同一组“相位色标”范围 / 刻度参数，默认 0–90°、15° 间隔；三者是不同的物理量，单位相同不代表数值等价。

定义：`Φ₂ = sqrt(det(Φ))`，`φ₂ = arctan(Φ₂) × 180/π`。图中色标上方同时注明两个公式。Φ 为 MTpy 计算的相位张量；使用其有符号行列式。当行列式小于零或非有限时，Φ₂ 与等效相位记录为 null，跳过椭圆填色，保留原几何与轮廓并在分析记录中说明；不取绝对值、不替换为 0°。行列式恰好为零对应有效的 0°。

实现只为当前绘图实例提供 Φ₂ 颜色数组，不改动安装的 MTpy 库、EDI、阻抗、插值规则、维性判定、椭圆大小 / 方位或感应箭头。没有采用 MTpy 2.1.4 中 `phidet` 的 `sqrt(abs(det))*180/pi` 快捷值。

`维性与相位张量参数.csv` 和 `MTpy分析记录.json` 新增 `phi2`、`phi2_phase_deg`、`phi2_reason` 字段。所有着色选项的分析数值相同，仅颜色选择不同。

验证：`tests/phase_coloring_test.py` 对已知张量检查实际 Matplotlib 椭圆填色、负行列式透明填色、公式、几何不变与 EDI 完整性；`tests/phase_coloring_integration.cjs` 使用后台 Electron、真实 78 个可读 EDI 的 1 / 100 s 两周期，检查控件、工程恢复、手动预览、PDF 标签和分层 AI 编辑包。所有输出隔离在全局目录/验证/v1.31.0，不启动或控制 Illustrator。

参考定义：[Caldwell et al. (2004)](https://doi.org/10.1111/j.1365-246X.2004.02281.x)；负行列式问题见 [2007 年关于该文的评论](https://academic.oup.com/gji/article/171/2/565/655656)。本版使用用户确认的实数定义，不进行绝对值扩展。
