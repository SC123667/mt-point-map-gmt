# v1.29.0 论文绘图默认参数（第一轮）

参考用户提供的 Kang et al. (2026), Ore Geology Reviews 198, 107617（DOI: 10.1016/j.oregeorev.2026.107617）图 1–6：弱化地形和构造背景、独立的科学量色标、周期与面板编号、黑白交替边框。实现为普通可编辑参数，不增加风格预设，也不复制论文数据或解释。

## 在哪里修改

- **制图样式**：黑白分段 / 普通细框、边框宽度与描线、Times New Roman / Arial、坐标与色标字号。
- **MT 绘图参数**：每边分段数、组图总宽、周期与编号位置和字号、β / φmin 着色、色标上下限和间隔、椭圆描边；原周期、椭圆大小、箭头比例、排版与色标位置继续可用。新控件在原参数面板下方，向下滚动可见。
- **地形底图**：色带、阴影强度、构造线宽和地质面填色不透明度倍率、名称形式。倍率只作用于绘图，不修改原构造几何或样式；区域框不受填色倍率影响。

MTpy 先修改参数，再点击 **更新预览**。保存工程记录全部新参数，撤销也包含这些参数。普通地图保持原自动预览流程。

## 默认值与旧工程

默认黑白框宽 2 pt、描线 0.5 pt、每边 8 段；字体 Times New Roman、坐标 / 色标 8 pt、周期 / 编号 9 pt；MTpy 组图宽 180 mm、图间距 3 mm。周期在左下、编号在右下；比例尺或箭头图例所在角会留出位置。地形默认低饱和色带、阴影 0.25，构造线宽倍率 0.8，地质面不透明度倍率 0.5，名称优先使用资料中已有的简称。

默认 β 为 −9 至 9°、间隔 3°；可切换 φmin，默认 0–90°、刻度间隔 15°。φmin 直接使用 MTpy 已以度表示的最小相位，不做二次角度变换。超出显示范围的值保留，并通过色标两端延伸标识；色标设置不筛除测点。MTpy 官方科学计算、插值门限、原始 EDI、箭头方向约定均不修改。

旧工程明确保存的地形、阴影、图间距、名称形式和科学参数继续使用旧值；新增字段缺失时采用本版默认值。因此旧工程要变浅可自行调整阴影，要使用简称可在“地形底图 → 构造名称形式”选择“优先使用已有简称”。未自动改写旧工程文件。

普通 GMT 地图的黑白框使用原生 `MAP_FRAME_TYPE fancy`，分段随经纬度刻度；MTpy 分段数单独可调，边框作为矢量对象输出。GMT 使用标准 Times-Roman / Helvetica 对应所选字体；MTpy 与其原生 AI 使用本机 Times New Roman / Arial。组图宽度是最终整张图的物理宽度；单周期中间文件仍保留内部画布尺寸。
